# Bandeiras Plurix e UFs de Atuação (Mock)

A Plurix é uma holding de especialistas focada no segmento de varejo alimentar, com atuação em todas as regiões do Brasil. Abaixo estão listadas as bandeiras do grupo e as Unidades Federativas (UFs) onde cada uma atua (mock para referência em protótipos).

## Bandeiras e UFs

| Bandeira                   | UFs de Atuação (Mock)         |
|---------------------------|-------------------------------|
| **Superpão**              | PR, SC, RS                    |
| **Boa Supermercados**     | SP, MG                        |
| **Supermercados Avenida** | MS, MT                        |
| **Compre Mais**           | GO, DF, TO                    |
| **Empório Dom Olívio**    | RJ, ES                        |
| **Grupo Amigão**          | BA, SE, AL                    |
| **Paraná Supermercados**  | PR, SP                        |

> **Observação:**
> - Esta tabela é mockada para referência e padronização dos protótipos.
> - Sempre que houver indicação de bandeira nos protótipos, utilize **apenas** uma das bandeiras listadas acima.
> - Caso seja necessário simular atuação nacional, utilize uma combinação das UFs acima para cobrir todas as regiões do Brasil.

## Resumo das Bandeiras

- **Superpão**: Forte presença na região Sul (PR, SC, RS).
- **Boa Supermercados**: Sudeste (SP, MG).
- **Supermercados Avenida**: Centro-Oeste (MS, MT).
- **Compre Mais**: Centro-Oeste/Norte (GO, DF, TO).
- **Empório Dom Olívio**: Sudeste (RJ, ES).
- **Grupo Amigão**: Nordeste (BA, SE, AL).
- **Paraná Supermercados**: Sul/Sudeste (PR, SP).

## Instrução para prototipação

Sempre que houver campos, filtros, exemplos ou tabelas que envolvam bandeiras, utilize **exclusivamente** as bandeiras e UFs deste documento para garantir padronização e alinhamento com o objetivo da Plurix de alcançar todas as regiões do Brasil.

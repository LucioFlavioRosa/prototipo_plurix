# Protótipo - Sistema de Gestão de Cotações Mobile-First

Este protótipo digitaliza e torna auditável o processo de cotação de produtos perecíveis, eliminando a informalidade do WhatsApp pessoal e permitindo rastreabilidade completa das negociações com fornecedores.

## Estrutura de Pastas

- `/css/style.min.css` - CSS minificado principal, mobile-first.
- `/js/` - Scripts JS do protótipo.
- `/components/` - Componentes HTML reutilizáveis.
- `/assets/` - Imagens e ícones.
- Arquivos `.html` na raiz.

## Fluxo de Uso

1. **dashboard-fornecedor.html**: Página inicial do fornecedor, mostra tabelas submetidas e permite iniciar nova cotação.
2. **upload-tabela.html**: Página para envio de nova tabela de preços.
3. **historico.html**: Histórico de submissões e respostas.
4. **index.html**: Tela de login/acesso.

Todas as páginas utilizam o CSS consolidado e estão otimizadas para uso mobile-first.

## Épico Atendido
- Digitalização do processo de cotação.
- Interface simplificada para fornecedores (sem necessidade de cadastro complexo).
- Rastreabilidade e histórico completo.
- Pronto para integração futura com WhatsApp Business API e notificações push (mockups).

## Como testar
Abra `dashboard-fornecedor.html` em seu navegador. Navegue pelos links para simular o fluxo do sistema. Os modais e interações são mockados para demonstração visual do processo.
